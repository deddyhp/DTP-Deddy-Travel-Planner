# DTP V0.2 — Real Journey Theme Update

Cloud-first Streamlit application for **Deddy Travel Planner**.

## Fokus update
- Homepage per perjalanan memakai **background custom**
- Trip Magelang menggunakan **foto hero sendiri**
- Status trip berubah menjadi **Completed Journey**
- Data ditata sebagai **planner + real journey database**
- Spot Guide memuat **catatan actual** dan **future decision**
- Tab baru: **Real Journey**

## Cara update GitHub
1. Ekstrak ZIP.
2. Upload seluruh isi folder ke repository GitHub DTP.
3. Commit changes.
4. Streamlit Cloud akan refresh otomatis. Jika belum, lakukan **Reboot app**.

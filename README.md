# DTP V0.1 — Magelang Healing

Cloud-first Streamlit application for **Deddy Travel Planner**.

## V0.1 scope
- Futuristic dark UI with yellow glow
- Mobile-first Home
- Current Mission based on Asia/Jakarta time
- Three-day timeline
- Spot Detail
- Why I Recommend
- Chaty's Notes
- Recommended menu
- Don't Miss and Attention
- Google Maps links

## Upload to GitHub
1. Create a new empty repository.
2. Choose **Add file → Upload files**.
3. Upload every file and folder from this package.
4. Commit the files.

Do not upload the outer ZIP itself as the application.

## Deploy to Streamlit Community Cloud
1. Open Streamlit Community Cloud.
2. Choose **Create app**.
3. Select the GitHub repository.
4. Main file path: `app.py`
5. Deploy.

## Utilization rule
After V0.1 is online, use it first. Journal, Packing, Expense, live Weather,
Gallery, and Review Book are intentionally deferred until real usage shows
what is genuinely needed.
